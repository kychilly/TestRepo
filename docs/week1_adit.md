## Baseline arms and fold safety

- **PCA + multinomial logistic regression:** completes end to end on the synthetic fixture. Standardization and PCA are fit only on the training partition; validation is used only for the configured C selection; test cells are not used for fitting or selection.
- **scVI probe:** structured methodological blocker. The required scVI/AnnData runtime and verified loader/checkpointed architecture are unavailable.

All arms consume the shared `PatientSplits` contract, including split hashing and independent pairwise overlap rejection. Prediction rows carry patient ID, cell ID, split, fold, seed, configuration hash, split hash, and model hash.

## Metric definitions and bootstrap

All manuscript metrics are generated by `src/evaluation` through `scripts/run_evaluation.py`. Cell-state metrics use fixed `AC`, `MES`, `NPC`, `OPC` ordering and include macro-F1, balanced accuracy, per-state metrics, confusion matrix, log loss, and Brier score. Patient-binary metrics include AUROC, AUPRC, balanced accuracy, sensitivity, specificity, Brier score, and calibration slope/intercept when estimable.

Bootstrap resampling is patient-level: a sampled patient contributes all of that patient's cells or patient record. Non-estimable replicates remain structured records and are not replaced with zero or unexplained NaN. The evaluator is the only approved source for manuscript metric files.
